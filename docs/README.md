# SoSID Toolkit Documentation

This folder contains the Sphinx documentation of the toolkit. All major
architecture and software decisions are logged in an Architecture Directory
Record ([ADR]) in Markdown format for future reference. Additionally,
[PlantUML] will be used for modelling of the architecture, which has a simple
text-based description, and interfaces to markdown, Sphinx, LaTeX, and more.
